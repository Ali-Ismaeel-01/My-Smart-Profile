## 📂 Pages & Features

### 🏠 Home (`index.html`)
The landing page sets the tone with a welcoming message and a sleek **image carousel**. It gives visitors a quick glimpse of what the site offers.

### 👤 About Me (`about.html`)
A personal overview section that includes:
- Short biography
- List of hobbies
- Personal goals

**Interactive element:** A *"Show More"* button reveals additional long-term ambitions, creating a clean and engaging layout.

### 📬 Contact (`contact.html`)
A fully functional contact form with fields for:
- Name, Email, Age, Gender
- Favorite programming language
- Message

**Features:** Form validation, responsive design, and user-friendly layout — all styled with Bootstrap.

### 💼 Portfolio (`portfolio.html`)
Showcases selected projects with:
- Project images and descriptions
- **Collapsible details** for each project
- A **project switcher** to browse through work

This page highlights web design and development skills in an interactive, visually appealing way.

### 🎉 Fun (`fun.html`)
An experimental playground with:
- **Image fade in/out animations**
- A **collapsible section** of fun web development facts
- **AJAX-powered random quote generator** — pulls quotes from `quotes.txt`

A page full of small surprises, designed to demonstrate creativity and interactivity.

### 🧠 Smart (`smart.html`)
The most dynamic page, packed with smart interactions:
- **Personalized greeting** with real-time name input
- **Hover-activated color changes**
- **Click-triggered animations**
- **Fade and slide effects**
- **Dark / Light theme toggle** (powered by jQuery)

This page showcases the advanced use of JavaScript, CSS transitions, and Bootstrap integration.
